# Importing cards and images

The Import tab accepts one or more card or token entries and sends them through the same content workflow used elsewhere in Halcyon.

## Import a card

1. Create or select a destination set.
2. Choose the **Import** tab and select the destination set.
3. Paste the complete card script into the editor.
4. Choose a rarity and, if needed, a front image and alternate-face image.
5. Add more entries or select **Import All**.

Halcyon reports the result for each entry. A failed entry is left available for correction so you can try again without rebuilding the entire batch.

## Import a token

Choose **Token**, enter the token script ID, and provide the script and image. Tokens do not use card rarity.
