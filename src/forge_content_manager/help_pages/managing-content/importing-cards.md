# Importing cards and images

The Import tab accepts one or more card or token entries and imports them into a custom set. Forge will automatically detect the imported cards and tokens when you next open the set in the Forge client.

## Import a card

1. Create the destination set if it doesn't exist yet.
2. Choose the **Import** tab and select the destination set. An empty entry will be created for you to start with.
3. Paste the complete card script into the input field.
   - You can also use the **Script Editor** to write or edit a script and then copy it into the input field afterward.
4. Choose a rarity and, if needed, a front image and alternate-face image.
5. Add more entries, or select **Import All** to finish.

Halcyon reports the result for each entry. A failed entry is left available for correction so you can try again without rebuilding the entire batch.

## Import a token

Choose **Token**, enter the token script ID, and provide the script and image. Tokens do not use card rarity.

## Notes

- If Forge doesn't recognize a card or token after import, check the Forge Paths in **Settings** to ensure the set is being stored in a location that Forge can read.
