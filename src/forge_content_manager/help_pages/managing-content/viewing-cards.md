# Viewing cards

The Cards tab allows you to view cards and edit their properties.

## Selecting a card

1. Navigate to the Cards tab and use the filters on the top to filter by set, rarity, etc.
2. Click on a row in the table for the card you want to view.

## Viewing card properties

Once you select a card from the table, a view shows up where you can see info about the card in question, including its card script, art, and rarity.

- This view also shows a list of all the alternate art printings defined for a card, visible in a list.
- For double faced cards, an option will be present to show the other side of the card. This will cause all the viewed cards to flip over. You can then view or edit the image for the other side of the cards.
- Double click on a card's art printing to enter a full screen view of the art. Click off of the card to close the view.

## Editing card properties

You can edit most of a card's properties via this view.

- Edit the card's script by typing in the input field. You can paste from the Script Editor if you want to as well.
- Add or remove alternate art entries by using the buttons on the bottom.
- For any art entry, you can edit its art by selecting it and then clicking Replace Image. If the back side of the card is currently visible when you do this, you'll replace the back side instead for double sided cards.
