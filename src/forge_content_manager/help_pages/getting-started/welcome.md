# Welcome to Halcyon

Halcyon helps you manage Forge custom sets, cards, images, packages, and scripts in one place.

## Finding your way around

- Use **Sets** to create and organize custom editions.
- Use **Import** to bring card scripts and images into a set.
- Use **Cards** to browse and edit the content you have imported.
- Use **Script Editor** to write, save, and import a Forge script.
- Use **Settings** to change the appearance and optional documentation sources.

The Help tab is bundled with the application, so these guides are available even when you are offline.

## A useful first step

If you are writing card scripts, start with [Using Auto for description autofill](../script-editor/auto-description-fill.md). It explains how to turn a natural-language description into a reusable script expansion.
